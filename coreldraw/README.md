# QALDIRG‘OCH — файлы для CorelDRAW

- Qaldirgoch_CorelDRAW.svg — векторная перерисовка, 300 × 300 мм; надписи в кривых.
- Qaldirgoch_CorelDRAW.pdf — векторный PDF, одна страница 300 × 300 мм.
- Qaldirgoch_preview.png — предпросмотр, 1600 × 1600 пикселей.
- source/draw.py — исходный код построения SVG из предыдущей беседы.
- SHA256SUMS.txt — контрольные суммы файлов комплекта.

SVG можно открыть или импортировать в CorelDRAW. Для получения CDR откройте SVG в CorelDRAW и сохраните как CDR. Собственный файл CDR в этой беседе не создавался.

Это стилизованная ручная векторная перерисовка по размытому образцу, а не точная автоматическая трассировка. Детали детей отличаются от оригинала.

При проверке текущей среды прежние файлы отсутствовали. Комплект восстановлен из кода, ранее выполненного в этой беседе, без изменения рисунка. SVG, PDF и PNG проверены. Предыдущие SHA-256 не записывались, поэтому побайтовое совпадение со старым комплектом не утверждается.

Для повторной генерации нужны Python, matplotlib и Inkscape. Скрипт записывает SVG в /workspace/work/output; затем SVG экспортируется Inkscape в PDF и PNG.
