# QALDIRĞOÇ — новая узбекская латиница

Надписи: QALDIRĞOÇ / 479-SONLI DMTT. Новый шрифт: Noto Sans Display Bold. Буквы Gʻ и Ch заменены на Ğ и Ç по новой редакции узбекского алфавита. Иллюстрация и круги сохранены без изменения.

- Qaldirgoch_CorelDRAW.svg — вектор, 300 × 300 мм; все надписи в кривых.
- Qaldirgoch_CorelDRAW.pdf — векторный PDF, одна страница 300 × 300 мм.
- Qaldirgoch_preview.png — предпросмотр, 1600 × 1600 пикселей.
- source/draw.py — код построения SVG, Python + matplotlib.
- SHA256SUMS.txt — контрольные суммы комплекта.

SVG открывается или импортируется в CorelDRAW. Установка шрифта для готовых SVG и PDF не требуется. Файл CDR не создавался.

Это стилизованная векторная перерисовка по размытому образцу; детали детей отличаются от исходника.

Новая редакция алфавита утверждена законом ÖRQ-1184 от 21.10.2026; предусмотрено вступление в силу через шесть месяцев после официального опубликования. На дату создания этой версии 11.11.2026 закон ещё не вступил в силу; эта версия выполнена по новой латинице по запросу пользователя.

Источники:
- https://lex.uz/en/acts/8548754
- https://gov.uz/oz/academy/news/view/237235
- https://notofonts.github.io/noto-docs/specimen/NotoSansDisplay/

Для повторной генерации используется /usr/share/fonts/truetype/noto/NotoSansDisplay-Bold.ttf. Скрипт записывает SVG в /workspace/work/output, затем SVG экспортируется Inkscape в PDF и PNG.
